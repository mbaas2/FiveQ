Privacy Policy

Last updated: November 2026 · Draft – please review before publishing

In short

FiveQ (iPhone, Apple Watch) and FiveQThoughts (Mac, Windows) do not collect any data for us. There is no tracking, no analytics, no advertising and no server of our own.

What data does the app process?

  • API key: Your TheBrain API key is stored only locally on your device (iPhone/Watch: app settings; desktop: local configuration file).
  • Quick Thoughts: Text, links and images you create or view are transferred directly between your device and TheBrain – either the local TheBrain desktop app (localhost) or TheBrain Cloud (api.bra.in). TheBrain Technologies' privacy policy applies to processing there.
  • Dictation: Dictation is processed by Apple's speech recognition (see Apple's privacy information).
  • Apple Watch: The API key is sent from your iPhone to your watch via Apple's WatchConnectivity.

This website

This site is hosted on GitHub Pages. GitHub may process technically necessary access data (e.g. IP address); see GitHub's privacy statement. We use no cookies and no analytics.

Kurz gesagt

FiveQ (iPhone, Apple Watch) und FiveQThoughts (Mac, Windows) erheben keine Daten für uns. Es gibt kein Tracking, keine Analyse-Tools, keine Werbung und keine eigenen Server.

Welche Daten verarbeitet die App?

  • API-Schlüssel: Dein TheBrain-API-Key wird ausschließlich lokal auf deinem Gerät gespeichert (iPhone/Watch: App-Einstellungen; Desktop: lokale Konfigurationsdatei).
  • Quick Thoughts: Texte, Links und Bilder, die du anlegst oder ansiehst, werden direkt zwischen deinem Gerät und TheBrain übertragen – entweder an die lokale TheBrain-Desktop-App (localhost) oder an die TheBrain Cloud (api.bra.in). Für die Verarbeitung dort gilt die Datenschutzerklärung von TheBrain Technologies.
  • Spracheingabe: Diktate werden über die Spracherkennung von Apple verarbeitet (siehe Datenschutzhinweise von Apple).
  • Apple Watch: Der API-Key wird vom iPhone über die Apple-WatchConnectivity-Verbindung an deine Uhr übertragen.

Diese Website

Diese Seite wird über GitHub Pages bereitgestellt. GitHub kann dabei technisch notwendige Zugriffsdaten (z. B. IP-Adresse) verarbeiten; siehe die Datenschutzerklärung von GitHub. Wir setzen keine Cookies und keine Analyse-Tools ein.
